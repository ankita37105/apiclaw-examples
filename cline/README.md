# Cline + APIClaw

In the Cline settings panel:

| Field | Value |
|---|---|
| API Provider | **OpenAI Compatible** |
| Base URL | `https://apiclaw.biz/v1` |
| API Key | your APIClaw key |
| Model ID | e.g. `apiclaw/claude-sonnet-5.5` (full list: `GET /v1/models` or the [model hub](https://apiclaw.biz/ui/model_hub/)) |
| Context Window / Max Output | the model's real values (from the model hub) |

Set the model for **both Plan and Act** modes.

Official guide: https://apiclaw.biz/docs/cline/
