# Continue (VS Code / JetBrains) + APIClaw

1. Copy [`config.yaml`](config.yaml) to `~/.continue/config.yaml` (or merge the `models` entry).
2. Put your key in `~/.continue/.env`:
   ```
   APICLAW_API_KEY=YOUR_API_KEY
   ```
3. Reload Continue and pick **APIClaw** in the model dropdown.

Official guide: https://apiclaw.biz/docs/vscode/
