# Cursor + APIClaw (custom OpenAI API key and base URL)

1. Cursor → **Settings → Models**.
2. Under **OpenAI API Key**, paste your APIClaw key.
3. Turn on **Override OpenAI Base URL** and set it to `https://apiclaw.biz/v1`.
4. Click **+ Add Custom Model** and enter a model ID from the [model hub](https://apiclaw.biz/ui/model_hub/) (e.g. `apiclaw/...`).
5. Turn **Auto** off and select your custom model in chat or agent.

Custom API keys in Cursor need a Cursor plan that allows them. Check Cursor's own docs.

Official guide: https://apiclaw.biz/docs/cursor/ · Background: https://apiclaw.biz/cursor-custom-api/
